## 为什么要自己搭

在社交平台发内容，最大的问题不是没人看，而是**你写的东西不属于你**。平台改一次规则，几年的积累可能一夜之间就没了。所以我想有一个自己的地方——哪怕只有一个读者。

这个博客就是结果。从决定到上线，大概花了三周，其中真正写代码的时间不到三天，剩下的时间都在做选择。

## 选型是最难的部分

我一开始想用 WordPress。它的好处很直白：有后台，点几下就能发文。但看到"服务器 + 域名 + 备案"这一套流程之后，我退回来了——对学生来说，每年几百块的固定支出和一堆实名流程，成本比技术本身更高。

后来试了静态站点生成器。核心逻辑很简单：

- 文章就是 Markdown 文件
- 一个构建工具把它变成 HTML
- 托管平台免费提供服务器和 CDN

最后我选了 Astro，原因是它默认不输出 JavaScript。对博客这种"以阅读为主"的站点来说，这是最合适的默认值。

## 我做对的三件事

**第一，先确定结构，再动手写。**

我花了一个晚上，在纸上画了所有页面的关系：首页、文章列表、文章页、分类、归档、关于、作品集。结构定了之后，写代码几乎不需要思考。

**第二，样式先做一套再复用。**

所有颜色、间距、字号都写成 CSS 变量。后面加页面时，我没有再写过一次颜色值。

**第三，没有一上线就追求完美。**

第一版很简陋。但它能跑、能发文章、能在手机上打开。剩下的都是慢慢加的。

## 我做错的一件事

我花了整整两天调一个悬停动画的曲线。后来发现，读者根本不会注意到那个动画。**时间应该花在内容和可读性上，而不是装饰上。**

如果你也想搭一个自己的博客，我的建议是：先想清楚你要写什么，再选工具。工具会过时，内容不会。
