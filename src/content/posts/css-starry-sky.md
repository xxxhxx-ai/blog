这个项目的目标很单纯：**不使用任何图片资源，只用 CSS 画出一片星空。**

## 为什么不用 Canvas

Canvas 能做更复杂的效果，但它需要一个 JS 渲染循环，会持续占用主线程。而这片星空只是装饰，不应该抢走阅读的注意力，也不该消耗电量。

纯 CSS 的星星是静态的，只在几个关键帧上做透明度和缩放的变化，性能开销接近于零。

## 怎么画出来

星星用 `box-shadow` 的伪元素批量生成：

```css
.stars::after {
  content: "";
  position: absolute;
  width: 2px;
  height: 2px;
  border-radius: 50%;
  box-shadow:
    12vw 18vh 0 0 #fff,
    34vw 62vh 0 0 #cfe4ff,
    71vw 12vh 0 0 #fff,
    88vw 81vh 0 0 #ffe4f2;
  animation: twinkle 5s ease-in-out infinite alternate;
}
```

一次声明就能画出几十个点，每个点的坐标和颜色都不同。再叠三层，分别用不同的动画时长（5s / 8s / 13s），就有了"不同步闪烁"的层次感。

## 呼吸感从哪来

单纯的闪烁很机械。真正让它"活"起来的，是三个周期互相错开：

- 星星闪烁：5s、8s、13s（互质，永不同步）
- 一层极淡的雾：`opacity` 在 0.4–0.7 之间以 21s 起伏
- 背景色相：在深蓝和深紫之间以 34s 缓慢漂移

三个不规则周期叠加，视觉上就不会有明显循环点。

## 一个取舍

我原本在星星后面加了一层模糊的星云，用 `filter: blur(60px)`。效果很好，但整个页面的滚动帧率从 60 掉到了 40 左右。

最后换成了一张 4KB 的 SVG 径向渐变。视觉差别几乎看不出来，性能完全恢复。

**教训：`blur` 很贵。能预渲染就不要实时算。**

## 结果

最终交付是一个 3.2KB 的 HTML 文件。没有图片、没有框架、没有外部依赖，打开就是一片会呼吸的星空。
