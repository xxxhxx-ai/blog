我又改了一次个人主页。这次做了一件以前不敢做的事：**把所有视觉样式删掉，只留纯文本，从头开始。**

## 第一步：只用系统默认样式

打开页面，就是浏览器默认的样子——宋体、16px、行高 1.15、没有边距。意外的是，页面的**信息层级居然还在**。标题大、正文小，能读。

这说明我之前的很多设计，其实是在掩饰结构不清的问题。

## 第二步：只调三件事

我给自己定了限制：这一轮只能改字号、行高、间距，不许改颜色，不许加装饰。

- 正文 16.5px，行高 1.95 —— 中文长文的最佳区间，比英文需要的行高更大
- 标题与正文的比例 1.62 : 1 —— 足够区分，又不至于像海报
- 段间距 = 行高 × 0.62

改完再看，页面已经很好读了。**大部分"设计感"，其实是节奏感。**

## 第三步：中英混排的细节

这一步最耗时间，但效果最明显：

```css
/* 中文正文的标点不要出现在行首 */
p { hanging-punctuation: first; }

/* 中英文之间自动留白（现代浏览器已支持） */
p { text-autospace: normal; }

/* 数字等宽，避免跳动 */
.mono { font-variant-numeric: tabular-nums; }
```

还有一条不成文的规则：中文正文用衬线体其实更耐读，但 UI 元素（按钮、标签、导航）必须用无衬线。这个博客就是这个策略——标题衬线，界面等宽，正文无衬线。

## 第四步：加回颜色

只加一个强调色，用在链接和可点击的地方。

加完我盯着页面看了很久，发现它比之前"设计过"的版本更安静，也更好看。因为**读者不需要在被装饰过的地方，费力寻找自己要找的东西。**

## 结论

排版不是把东西变漂亮。排版是决定**读者的眼睛按什么顺序走**。

顺序对了，加什么颜色都不难看；顺序不对，加多少特效都救不回来。
